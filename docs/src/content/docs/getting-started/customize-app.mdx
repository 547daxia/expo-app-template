## Splash screen and app icon

Update the app icon and splash screen images in `assets`. This CNG template applies them the next time you create a native build; run `pnpm prebuild` only when you intentionally need to inspect generated native projects.

Development, preview, and production use distinct bundle identifiers and schemes but currently share the same icon assets. Add variant-specific assets only if your release process requires them.

For more details about the app icon and splash screen, please refer to the expo documentation.
