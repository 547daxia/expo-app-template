## What is included

<CardGrid stagger>
  <Card title="Canonical documentation" icon="open-book">
    The repository Markdown is the single source of truth. This site renders it
    for navigation, search, and AI-friendly llms.txt output.
  </Card>
  <Card title="Expo SDK 56 + CNG" icon="star">
    Expo Router, a development client, and Continuous Native Generation keep
    native configuration reproducible without committing generated projects.
  </Card>
  <Card title="Feature-oriented app" icon="add-document">
    Onboarding, guarded authentication, Feed, Settings, and an interactive
    Style Demo demonstrate the repository boundaries.
  </Card>
  <Card title="Typed foundations" icon="setting">
    TypeScript, TanStack Query, TanStack Form, Zod, Zustand, SecureStore, MMKV,
    FlashList, Jest, and Maestro are configured as project defaults.
  </Card>
  <Card title="Local native module" icon="setting">
    A minimal Expo Module demonstrates Kotlin, Swift, a typed TypeScript facade,
    Web fallback, autolinking, and CNG verification.
  </Card>
  <Card title="Quality and releases" icon="document">
    GitHub Actions, EAS profiles, dependency checks, documentation validation,
    and release gates provide a maintainable starting point.
  </Card>
</CardGrid>
